# Pengu: your desktop coding mentor (Windows 10/11)

## Before you start
1. Install **VS Code**: https://code.visualstudio.com/ (keep "Add to PATH" ticked in the installer).
2. Have a language you want to practice installed (Python, Node.js, Go or Java). Not required to start.

## Run
1. Unzip `Pengu-win.zip` anywhere (e.g. your Desktop).
2. Double-click `Pengu.exe`.
3. Windows may say **"Windows protected your PC"**: click **More info → Run anyway**. (The app is not code-signed yet.)
4. A penguin appears on your desktop. Drag it anywhere.

## Learn
1. **Click the penguin** → the dashboard opens.
2. Pick a course (**DSA Interview Prep** or **System Design Basics**) → **Start**. VS Code opens your own copy of the course
   (in `Documents`-like folder `%USERPROFILE%\PenguLearn`). Your edits are never overwritten.
3. Open a lesson folder, read its `README.md`, pick ONE language file and fill in the TODO.
4. As you code, Pengu watches and asks you questions in a speech bubble, like an interviewer would. It never hands you the answer.
5. The dashboard shows progress per course; the **Progress** page lists your recurring mistakes and what to improve.

## Privacy
No account. Pengu creates an anonymous ID. The code you write inside Pengu courses is sent to the Pengu server so an AI can review it.
Don't paste secrets into course files.

## Trouble?
- "VS Code not found": install it, then restart Pengu.
- No bubbles for a minute: the server may be waking up; keep coding.

# Binary Search

Given a **sorted** list of distinct integers and a target, return the index of the target, or `-1`.

Your solution must take O(log n) time: a hidden test searches a million elements.

```
binary_search([1, 3, 5, 7, 9], 5)  -> 2
binary_search([1, 3, 5, 7, 9], 4)  -> -1
```

Pick ONE language file in this folder (solution.py, solution.js, solution.go or Solution.java), delete nothing, and fill in the TODO.
Think about: the empty list, a single element, and a target outside the range.
